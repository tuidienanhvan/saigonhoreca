# Nhật ký Cập nhật hệ thống
Hành trình tiến hóa của Pi Dashboard, từ những tính năng nhỏ nhất đến những bước ngoặt lớn về công nghệ.

---

## v2.5.0 — Onboarding & Help Center
*Ngày phát hành: 04/05/2026*

**Highlight: Hệ sinh thái Trợ giúp thông minh**
- **Help Center PRO**: Giao diện tài liệu mới, hỗ trợ Search realtime và Markdown.
- **Onboarding Tour**: Hướng dẫn người dùng mới (Step-by-step) làm quen dashboard.
- **Floating Context Help**: Nút trợ giúp thông minh gợi ý bài viết phù hợp.
- **UI Typography Refinement**: Tối ưu hóa khoảng cách dòng và font chữ.

---

## v2.4.0 — Marketing Automation
*Ngày phát hành: 15/04/2026*

**Highlight: Visual Funnel Builder**
- Trình kéo thả xây dựng phễu bán hàng (Landing Page -> Lead -> Email).
- Theo dõi tỷ lệ chuyển đổi (Conversion Rate) thời gian thực.
- Tích hợp sâu với module Email Campaigns.

---

## v2.3.0 — Performance & NanoCache
*Ngày phát hành: 01/04/2026*

**Highlight: Tối ưu tốc độ**
- Triển khai lớp NanoCache giúp tốc độ phản hồi nhanh gấp 3 lần.
- Tự động tối ưu hóa ảnh sang định dạng WebP.
- Hỗ trợ PWA (Progressive Web App).

---

## 🤖 v2.2.0 — AI Cloud Gateway
*Ngày phát hành: 15/03/2026*

**Highlight: Trung tâm điều phối AI tập trung**
- Hỗ trợ đa nhà cung cấp: OpenAI (GPT-4o), Anthropic (Claude 3.5), Google (Gemini 1.5).
- Hệ thống **API Vault**: Quản lý khóa API và hạn mức sử dụng tập trung.
- AI Assistant tích hợp sâu vào editor và SEO module.

---

## 🔍 v2.1.0 — SEO AI Bot
*Ngày phát hành: 01/03/2026*

**Highlight: Tự động hóa SEO bằng trí tuệ nhân tạo**
- Bulk Meta Generation: Tạo tiêu đề và mô tả SEO cho hàng loạt bài viết.
- Suggestion Internal Links: Gợi ý liên kết nội bộ thông minh.
- Schema.org tự động cấu trúc cho các bài viết.

---

## 💡 Luôn luôn lắng nghe
Chúng tôi liên tục cập nhật Pi Dashboard dựa trên phản hồi từ chính các bạn. Nếu bạn có ý tưởng cho một tính năng mới, đừng ngần ngại gửi yêu cầu cho đội ngũ phát triển tại mục **Feedback**.
